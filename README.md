# Hero Incremental Wiki

Codes, heroes, tier list, rank ladder, rune odds and calculators for **Hero Incremental** on Roblox.

Live site: served by GitHub Pages from this repo (`index.html` + `img/`).

## Editing

- Edit `page.html` (all content, styles and game data live in it).
- Run `python build.py` to regenerate `index.html`, then commit and push.
- Game data (heroes, codes, ranks, runes, patch notes) is in the `<script>` block near the bottom of `page.html`.
