How to redeem

  2. Scroll to the Codes section at the bottom.
  3. Type the code exactly as shown and press Use.

Codes FAQ

What are the working Hero Incremental codes?

The working codes are LAUNCH, STURMFESTE, THANKYOU. LAUNCH gives +50 Cargo and 20 minutes of 2× Credits. STURMFESTE gives +40 Crowns and 15 minutes of 2× Credits. THANKYOU gives +1 Hero Token.

How do I redeem codes in Hero Incremental?

Join the game, press X to open the Shop, scroll to the Codes section, type the code and press Use. You can also redeem codes from the Settings menu (the gear icon).

Why is my Hero Incremental code not working?

Each code works once per account, so it may already be redeemed. Check the spelling. STURMFESTE only works after your first promotion to Silver, and expired codes stop working after their end date.

When do new codes come out?

New codes are released with game updates and milestones. This page is updated whenever a code is added or expires.
